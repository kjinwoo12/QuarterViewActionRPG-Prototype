# 주인공 3D 모델 (Vita 기반)

- 원본: VRoid "Vita" (CC0) — github madjin/vrm-samples vroid/beta/Vita.vrm
- 개조: 핑크 단발, 검은 크롭탑/핫팬츠, 흰 두루마기(붉은 단, 넓은 소매), 어글리 슈즈(하이힐 부츠 삭제)

| 파일 | 용도 |
|---|---|
| gil_protagonist_for_mixamo.fbx | 믹사모 업로드용. 뼈대 없는 메시+텍스처 내장, T포즈 → 오토리거로 리깅 |
| gil_protagonist_rigged.fbx | VRoid 뼈대(J_Bip_*) 포함 FBX. Unity Humanoid 임포트용 |
| gil_protagonist.glb | 같은 모델 glTF |
| gil_protagonist.blend | 블렌더 원본 (텍스처는 textures/ 참조) |
| Vita_original.vrm | 개조 전 원본 |
| textures/ | 색 바꾼 텍스처 PNG |

믹사모 팁: 업로드 후 턱·손목·팔꿈치·무릎·사타구니 마커를 찍으면 됨. 넓은 소매 때문에 손목 마커는 소매 끝이 아니라 실제 손목에 찍을 것. Skeleton LOD는 "Standard"(손가락 포함) 권장.
